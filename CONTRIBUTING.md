# Contributing

- Never commit images, PDFs, or anything under `data/sessions/`. The `.gitignore` enforces this; please don't override it.
- Public datasets go in as *manifests* (CSV/JSON with URLs + licence), not files.
- Report model metrics stratified by Fitzpatrick skin type (I–VI). Unstratified accuracy numbers will be asked to be redone.
- Open an issue before large changes. Small fixes: just send a PR.
